## 内容放哪里

| 目录 | 作用与维护边界 |
|---|---|
| `资料/面经/` | 单场面试档案，保留当时回答、当时复盘与改进摘要 |
| `资料/学习材料/` | 外部摘录、历史笔记与学习参考 |
| `资料/项目参考/` | 第三方项目资料，不作为本人经历证据 |
| `wiki/公司画像/` | 问题分布、业务差异、准备重点和面经链接 |
| `wiki/技术主题/` | 一份完整的当前技术解释，作为通用答案的主专题 |
| `wiki/Agent问题答案/` | 具体问法的短答、差异与主专题链接 |
| `wiki/项目追问/` | 本人项目的完整追问答案，通用原理链接技术主题 |
| `wiki/我的简历/` | 本人事实的核对依据 |
| `wiki/模板/`、`wiki/索引/`、`wiki/dashboard/`、`wiki/scripts/` | 写作模板、分类导航、统计与维护工具 |

同一个技术问题可以出现在多场面经里；它的完整当前解释只在主专题维护。历史回答保留原貌，后续修订写摘要并链接主专题。[[LLM Wiki与RAG的区别及适用场景]] 已从原专栏迁入技术主题。

## 工作约定

- 新面经从 [[模板/录音转面经]] 或 [[模板/新面经原文]] 起步，放到 `资料/面经/<公司>/<BU>/`；TikTok / TT 统一归入字节。
- 新主题先查 [[index]] 与 [[索引/主题]]；已有主题就更新，独立新主题才用 [[模板/新主题文章]]。来源材料按需保留，不要求另写一份长文。
- 公司画像只汇总问题、业务差异与准备重点；完整解释链接主题，见 [[模板/新公司画像]]。
- 本人项目事实先核对 [[我的简历/README]]，项目答案按 [[模板/新追问QA]] 集中维护。
- 新增、删除或重命名 wiki 页面后，同步总索引与相关分类索引，追加日志。
- 完成后运行 `python3 wiki/scripts/lint_wiki.py`。wiki 断链会令检查失败，资料历史断链另列提示。

算法内容在另一个仓库。双链、日志与搜索的具体规则见 [[使用指南]]。
