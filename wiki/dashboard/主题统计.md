# 主题统计

> 查看主题之间的链接与公司关联；链接数量包含索引、日志等导航引用，不直接代表面试频次。

## 全主题（按引用次数排序）

```dataview
TABLE WITHOUT ID
  file.link AS "主题",
  domain AS "域",
  length(file.inlinks) AS "被引用次数",
  length(file.outlinks) AS "引用别人次数"
FROM "wiki/技术主题"
WHERE type = "topic"
SORT length(file.inlinks) DESC
```

## 主题被哪些公司画像引用

```dataview
TABLE WITHOUT ID
  file.link AS "主题",
  filter(file.inlinks, (l) => contains(l.path, "wiki/公司画像/")) AS "出现于公司"
FROM "wiki/技术主题"
WHERE type = "topic"
LIMIT 20
```

## 孤岛主题（无引用）

```dataview
LIST
FROM "wiki/技术主题"
WHERE type = "topic" AND length(file.inlinks) = 0
```

> 这里统计没有任何入链的页面；总索引也计入入链。是否有公司关联，请看上面的专门表格。

## 没填 domain 字段的主题

```dataview
LIST
FROM "wiki/技术主题"
WHERE type = "topic" AND !domain
```

> domain 字段缺失会让"按域分组"失真，慢慢补一下。

---

## 用法

- 用 "被引用次数" 查看链接分布；安排复习优先级时结合真实面经与公司考点
- 看 "出现于公司" 决定哪些主题该重点准备
- 孤岛主题 → 检查双链 / 删除 / 暂时不管

## 添加新主题

参考 [[模板/新主题文章]]。frontmatter 必填 `domain`：

```yaml
---
title: <主题名>
type: topic
domain: 数据库 | 缓存 | Java | 中间件 | 网络 | Agent
tags: [...]
---
```

加完后跑 `/wiki-lint` 验证。
