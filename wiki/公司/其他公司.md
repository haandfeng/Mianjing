## 星河觉醒（AI/Agent 方向，秋招正式岗 · **面试中**）

- [[公司/星河觉醒/Agent方向/星河觉醒Agent一面_2026-07-20]] —— 一面（**过**，约下轮）：85 分钟几乎零八股，谷歌 Memory 连环 6 问 + 字节 DeerFlow 连环 8 问 + LC698
- [[公司/星河觉醒/Agent方向/星河觉醒Agent二面_2026-08-07]] —— 二面（未知）：**43 分钟，字节答疑 Bot 单线深挖 18 问占 55%** + 树上标记均匀分布（LC979 的 N 叉推广，只讲思路）

**两轮的关系：一面挖「你怎么做的」，二面挖「你怎么知道它有用」**——从工程实现一路推到评测方法论再推到线上产品化。**同一个项目，问的层次完全不同，别按同一套准备。**

- **风格**：纯项目工程深挖，几乎零八股；给提示极克制（二面算法卡 6 分钟只说了一句话）；**对评测方法论异常敏感**——样本量 → 跑几轮 → 方差 → 分数来自哪些维度 → 怎么再提 8 个点 → 线上怎么样 → 怎么设计线上指标，**七问一气呵成**
- **一面暴露的坑**：在职项目边界外模块被追问（主题结束判断、embedding 实现）答「没细究」
- **二面暴露的坑（更结构性）**：① **这个项目没有任何线上度量**——问幻觉率和问线上解决率两次都空手 ② **数字口径四组打架**（87 / 0.80~0.86 / 0.78→0.86 / 弃用的 90%）③ **不知道 spec-driven development 是什么**（已补课，见二面文件 Q11）
- **公司业务三大类**（二面反问问出来的）：① 传统业务迭代 ② Agent 方向（**记忆**、for 研发效率 / 运营效率 / C 端）③ 基建（AB 实验平台、流量分发、网关 + **大模型网关 / 分发 / 调度平台**）
- **用人要求**：创业公司**没有命题作文**，要自己找问题、自己分析、自己解决；**发现更好路径要能快速掉头**，不是闷头往前冲
- 关联：[[Agent设计模式与MCP]] · [[追问/字节答疑Bot]] · [[幻觉与事实性评测]] · [[谷歌实习]] · [[字节实习]]

## 点点互动（AI 中台部门 · AI Agent 工程师 · **人才计划**）

- [[公司/点点互动/AI Agent方向/点点互动AI Agent一面_2026-07-27]] —— 一面（**通过**，进业务二面）：**古法编程算法题（LC2531，禁 AI 投屏手写）+ 字节项目深挖 38 分钟 + Agent 概念题**
- [[公司/点点互动/AI Agent方向/点点互动AI Agent二面_2026-08-05]] —— 二面（未知，「内部同步再推进」）：**26 分钟纯 BQ，业务负责人面**。23 题里 11 题在反复问同一件事（会不会跳 / 我们是不是备胎）；唯一技术题是「Claude Code / Codex / OpenClaw 源码有什么设计好」
- 业务：游戏公司的 AI 中台——①给项目组提供中台能力（模型调用、协议适配、媒体生成、自动翻译）②探索**端到端游戏生成 Agent**（目标生产级）
- 流程：业务侧 2 轮 + HR + 可能 CTO 面，**共 4-5 轮**。**一面纯技术，二面纯动机**——两轮性质完全不同，别按同一套准备
- 风格：**一面先算法后项目**；项目问得细且连贯（链路 → 为什么有效 → 缺点 → 选型对比 → 协议差异 → token → cache → 线上 bug → trace → 评测方法论），**每个技术点都要能回答「为什么」和「代价是什么」**
- **二面风格：同一件事换四个角度反复问**（为什么这么多实习 / 拿到谷歌 offer 就从字节离职吗 / 本来说干到 9 月 / 当初为啥不多实习），**技术回答几乎不追问**
- 一面三场里项目表现最好；失分在算法题（23 分钟 + 复杂度答错）和「token 差异说没细究」
- 二面失分：「做实习是为了丰富简历」「因为谷歌有 title」「昨天面米哈游把我挂了」「并不排斥游戏公司」——**四句都是主动递刀**；技术题把架构复杂度归因成「对模型不自信」（正确口径是「约束不同」）
- 二面亮点：「最好结果是不是谷歌 return offer」没顺着答是，给了可验证的理由（中国业务边缘 / 只能做外围 evaluation）——**和一面「主动纠正面试官预设」是同一能力，已稳定复现两次**
- 关联：[[Agent设计模式与MCP]] · [[追问/字节答疑Bot]] · [[Agent记忆四家实现对比]] · [[追问/谷歌Memory]]

## 懂车帝（创作平台 · 图文视频 AIGC · 🔴 **一面挂**）

- [[公司/懂车帝/AIGC创作方向/懂车帝AIGC创作一面_2026-08-10]] —— 一面（**挂**）：**54 分钟，Agent 通用概念题占了一整块（9 分钟）** + 字节答疑 Bot 五问 + AI coding 三连 + **LC11 盛最多水的容器（19 分钟，走了单调栈没走双指针）**
- 🔑 **事后归因（这条比任何单题都值得记）**：**答得最好的题区分度最低，区分度最高的题答得最差。** 概念块（skill/workflow 边界、上下文工程）满分但不加分——谁读过官方博客都能答；而**平台岗核心题（企业级 agent 能力 = 三个形容词）、创作类头号难题（评测 = 零结果）、编码（19 分钟走弯路）、岗位表态（反问零钩子）四项全失**。硬信号两负一空，软信号再满也翻不过来
- **业务**（反问问出来的）：**创作类 AIGC**——图文视频的创作平台，**面向 C 端创作者**，做**通用的创作能力**。⚠️ 跟我全部三段 agent 经验（B 端、文本、查证类）差异极大，**下轮必须准备「创作类输出没有唯一正确答案，怎么评测」这条线**
- **风格：扫描式一题一问，几乎不连追**——问完拿到答案就走下一题，跟字节二面那种咬住一条链问六次完全相反
- **⭐ 最值得注意的题型变化：一整块是跟项目无关的通用概念题**——skill / workflow / tool / agent 的职责边界、什么时候用 skill 什么时候用 workflow、workflow 什么场景是**必须**的、什么是上下文工程、企业级 agent 该具备什么能力、agent 之间怎么通信。**前六场一次都没考过，而这块纯靠准备就能拿满分**
- **答得好的**：退出逻辑三种情况一次讲完（原生退出 / 门禁回灌 / 审核升级，统一在「合成一条工具消息」上）；vibe coding 六个动作全具体，尤其「**AI 写的测试样例基本肯定能测对，因为它照着自己要写的代码写**」；skill/workflow 边界答全并点名了 Claude Code 的 JS dynamic workflow
- **失分（全是复发老毛病）**：① 编码题 19 分钟且**全程没跟面试官对过方向** ② **反问零钩子**（面试官摊开「创作 AIGC / 图文视频 / C 端 / 通用能力」四个点，一个没接，第三次复发）③ **全场零数字**（56% / 87% / 200+ / 50+ 一个没报，而且专门问了评测飞轮）④「没有 / 不是我负责的」开局 3 次 ⑤ 企业级 agent 三条全是形容词没判据
- 关联：[[追问/字节答疑Bot]] · [[Agent设计模式与MCP]] · [[AI-Coding工程实践]] · [[RAG优化全链路]]
