## 本场考察重点

1. **项目机制与边界** —— 从“做了决策树”追到状态存哪、停止条件怎么改、树如何生成、哪些分支静态分析看不到、审核 Agent 能不能证明完整。
2. **Agent Memory 事实准确性** —— 不只问自己的 Memory，还要求比较开源实现；产品名、触发时机、晋升指标和来源类型都必须说准。
3. **评测是不是独立裁决者** —— 自进化 Memory 要说明候选版本、数据集隔离、退化回滚和如何防止只拟合固定评测集。
4. **系统与模型基础** —— Arm Causal Profiling（因果性能剖析）、CUDA（NVIDIA 的 GPU（graphics processing unit，图形处理器）并行编程平台）经验与 Attention 计算过程都会问；不会 Attention 是本场明确断点。
5. **车载语音全链路** —— ASR（automatic speech recognition，自动语音识别）只是其中一层；真正分水岭是多人车厢中的说话人分离、受话对象判断、安全执行、打断和端云时延。
6. **研发基本功与动机** —— 会直接确认主语言、能否独立编码、为什么从系统转向 Agent、优势短板和回国稳定性。

## 真题与答题骨架

> **决策树也是模型生成的，怎么保证没有遗漏？** 出处 [[资料/面经/小鹏汽车/智能座舱/小鹏汽车智能座舱端侧Agent一面_2026-09-18#5. 决策树也是模型生成的，怎么保证没有遗漏？]]
> 不能承诺绝对保证。对抽象语法树可枚举的真实分支，用已验证数 / 总分支数衡量覆盖率；审核 Agent 重新读代码，只能降低遗漏率。运行时配置、反射、下游返回值和跨仓库动态调用要明确标成静态分析盲区，最终用回归集验收。

> **怎样减少上下文和 token？** 出处 [[资料/面经/小鹏汽车/智能座舱/小鹏汽车智能座舱端侧Agent一面_2026-09-18#8. 怎么减少上下文和 token？做过上下文压缩吗？]]
> 分两层：上下文压缩把早期轨迹变成目标、进度、关键文件和待办；卸载（offload，把大结果写入磁盘）只在上下文保留路径和摘要。压缩后必须用同一回归集检查质量，不能用“轮次越多越好”代替停止条件。

> **开源 Agent 的 Memory 有什么差异？** 出处 [[资料/面经/小鹏汽车/智能座舱/小鹏汽车智能座舱端侧Agent一面_2026-09-18#9. 看过哪些开源 Agent Harness？Memory 有什么不同？]]
> DeerFlow 每轮后异步抽取；Codex 对空闲会话先抽取、再由专职 Agent 合并；OpenClaw 用定时 Dreaming 和多信号门禁晋升。差异来自作用域、后台算力、写入时延和错误代价，不是厂商是否“相信自己的模型”。

> **设计车载语音 Agent，关键点和挑战是什么？** 出处 [[资料/面经/小鹏汽车/智能座舱/小鹏汽车智能座舱端侧Agent一面_2026-09-18#18. 设计一个车载语音 Agent，有哪些关键点和挑战？]]
> 固定六层：多麦克风声学前端 → 流式语音识别 → 受话对象判断与会话控制 → 意图和工具路由 → 确定性安全执行 → 弱算端、强算端、云端协同。指标不能只看回答质量，还要看误唤醒、受话对象误判、字错误率、端到端长尾时延和高风险误执行。

> **多人车厢里，怎么知道用户是在和车说话？** 出处 [[资料/面经/小鹏汽车/智能座舱/小鹏汽车智能座舱端侧Agent一面_2026-09-18#19. 多人车厢里，怎么知道用户是在和车说话？]]
> 这是受话对象判断，不等于声纹识别。融合座位方向、说话人分离、声纹、文本意图和会话历史；低置信度先澄清，高风险动作再确认。任何单一信号都不能直接做裁决。

> **Attention 的计算过程是什么？** 出处 [[资料/面经/小鹏汽车/智能座舱/小鹏汽车智能座舱端侧Agent一面_2026-09-18#15. Attention 的计算过程是什么？]]
> 输入映射成 Q（query，查询向量）、K（key，键向量）、V（value，值向量）；计算 `QKᵀ / √dₖ`，加因果掩码，经 softmax 得到权重，再乘 `V`。多头注意力并行做多组后拼接。

## 团队与岗位信息

- 面试官口述大方向同时覆盖自动驾驶和座舱智能，本岗位属于座舱对话系统。
- 团队运行形态是弱算芯片、强算芯片、云端三端协同。
- 大头工作是端侧 Agent Harness、声学与工具调用接入；少量方向涉及模型部署、推理优化和编译器。
- 现阶段以用户触发的响应式 Agent 为主，也在探索由系统主动发起任务的主动式 Agent，以及与自动驾驶 Agent 的联动。
- 校招生画像：一项能力做深、基础扎实；有好奇心和持续学习能力；能沟通协作。
