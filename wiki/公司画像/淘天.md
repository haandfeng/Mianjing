# 淘天

## 概览
- 方向：AI Agent（应用层，非算法）
- 难度：中高 —— **零八股、零算法**，1 小时 16 题全部围绕你简历里的 RAG / 多智能体 / MCP / LangGraph **实现细节**深挖
- 一句话画像：**方向都在常规范围内（RAG、MCP、多智能体），但每一题都会追到"你到底踩过没踩过"那一层**——背概念能过第一问，答不出第二问。所有回答必须能落到具体数字、具体参数名、具体报错

## 考察重点（按出现次数排序）

1. **MCP 深度（5 题，本场最重）** —— 标准化接口设计 / 入参出参具体举例 / 没有 MCP 之前的工具调用原理 / 缺点与挑战 / 结果是否支持流式。**不是问"MCP 是什么"，是问你封装时遇到了什么**
2. **LangGraph 工程细节（4 题）** —— State 全局管理 / Checkpoint 机制 / 并发状态竞争 / 节点结果实时流式 / 为什么不用 LangChain
3. **RAG 混合检索（3 题）** —— 两路结果融合逻辑、混合策略在哪个环节起作用、OCR 与表格结构化的坑、识别准确率怎么量化
4. **失败处理与降级** —— 子任务空数据怎么重试降级（**「空结果不是异常」是这题的分水岭**）
5. **架构选型自陈** —— 是不是主子 agent、为什么，能否说出所选方案的代价
6. **项目量化** —— 一次会话多少 token、有没有超限、模型具体哪个版本
