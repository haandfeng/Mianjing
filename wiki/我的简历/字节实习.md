# 字节跳动实习（2026/04 – 2026/06）

## 简历原文（逐条）

> 主导基于 **DeerFlow**（LangGraph）二次开发**复杂业务答疑飞书 Bot**，服务 TTO 广告平台运营/产品/研发 **200+** 用户。

> 设计**多 Agent 编排**降低复杂业务问答的以偏概全与幻觉。**决策树门禁**促使主 Agent 分类讨论、梳理上下游逻辑。**审核 Agent** 兼具审核与反问、引导用户框定范围。"逐分支验证 + 审核"落为硬约束，准确率 **56% → 87%**。

> 适配字节内部网关，打通 **Gemini / Anthropic / OpenAI** 多协议大模型接入层，统一支持开启**最高强度思考模式**（性能 +10%）并实现 **prompt cache** 降本增效；定位修复 **httpx 连接池跨事件循环**致 Event-loop-closed 等生产疑难 bug，提升线上稳定性。

> 基于字节 **Fornax** 搭建 **Trace 链路与评测数据飞轮**：全链路请求可追踪、持久化，横向对比不同 **harness 框架**性能；每次问答沉淀专家评价 + 每周评审周报，以真实质量信号驱动迭代，累计 **50+** 条可复用回归评测集。

## 当前指标定义

按 [[项目追问/字节答疑Bot#Q10 口径统一 ②：这个数叫「准确率」还是「平均得分率」？（🔴 2026-08-17 快手三面被面试官当场点破）]] 保存的后续确认，56% → 87% 指固定评测题上的**平均得分率**。上方简历原文保留当时的“准确率”措辞；复述当前指标时使用平均得分率，不能据此宣称线上问题的正确率。评分方法与面试答法在该追问章节维护。
