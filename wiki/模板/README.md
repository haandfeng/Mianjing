# 模板索引

加新内容先选模板；已有主专题或项目追问时优先更新，避免再建一份完整答案。

| 何时用 | 模板 | 输出位置 |
|---|---|---|
| 整理录音或转载面经 | [[录音转面经]] | `资料/面经/<公司>/<BU>/<标题>.md` |
| 手敲面经，或新建待填写的单场档案 | [[新面经原文]] | 同上 |
| 新建公司画像 | [[新公司画像]] | `wiki/公司画像/<公司>.md` |
| 新建独立技术主题 | [[新主题文章]] | `wiki/技术主题/<主题>.md` |
| 集中本人项目追问 | [[新追问QA]] | `wiki/项目追问/<项目>.md` |

## 怎么用

可以让 LLM 读取模板后整理，也可以复制模板中的正文、替换占位符。新建待填写档案直接使用 [[新面经原文]]；不调用已移除的复盘脚本，也不另建一套复盘目录。

- 面经保存原问题、当时回答和当时复盘；缺失的现场回答留空，不推测。
- 逐题复盘先列当时回答，等本人判断后再讨论，确认后写改进摘要。
- 完整通用答案维护在技术主题；完整项目答案维护在项目追问，事实以我的简历为准。
- 完成后更新公司画像、受影响的索引与日志，并跑 `python3 wiki/scripts/lint_wiki.py`。

## 现有属性

面经文件必填 `type/company/bu/round/date/verdict/source/tags`；公司画像必填 `last_interview/tier/passed/failed/pending`，其余按模板现有字段填写。日期或结果未知就写“未知”，不能补造。

这些属性供 [[dashboard/README]] 查询；具体字段示例见各模板。算法内容在另一个仓库。
