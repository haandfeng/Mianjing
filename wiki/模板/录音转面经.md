# 录音 / Copy → 面经

把录音转录或转载原文整理成单场档案，保留来源与当时表现，不自动生成一套完整的新答案。

## Prompt 模板

```text
任务：把下面的面试原始内容整理为一份标准面经，参考 wiki/模板/新面经原文.md。

输入类型：自己的录音转录 / 网上转载
公司：__
BU / 部门：__（未知就填“未知”）
轮次：__
日期：__（可填已知的约略日期；完全未知填“未知”）
结果：__（通过 / 挂 / 未知；转载无结果填“未知”）
来源链接或材料说明：__

【原始内容】
__

输出要求：
1. frontmatter 必须包含 title/type/company/bu/round/date/verdict/source/tags。
   type 填“面经”；source 填“我面试”或“网上转载”；tags 按内容填3–8个。
   TikTok / TT 的 company 统一填“字节”，业务方向保留在 bu 和目录中。
2. 按原顺序保留问题、追问与可核实的现场回答。自己的面经使用
   “当时的回答”“当时复盘 / 改进摘要”“当前知识链接”。没有现场证据就留空。
   转载保留原文已有的回答，没有回答时只列问题，不编造当时答法。
3. 输入已包含的历史复盘可以整理；新的逐题复盘先只列原话，等本人判断，
   再共同打磨。本人确认后写改进摘要，不在入库时抢先补全。
4. 完整通用答案只在现有 wiki/技术主题/ 的主专题维护；完整本人项目答案
   放 wiki/项目追问/，面经只写摘要并链接。项目事实先核对 wiki/我的简历/。
5. 双链只链接已存在的页面。参考资料放资料/学习材料/；不要求为每场面经
   新建技术长文。算法内容转另一个仓库。
6. 保存到 资料/面经/<公司>/<BU>/<标题>.md；BU未知可直接放公司目录。
```

- [ ] 文件放到正确公司目录，属性完整。
- [ ] 对应公司画像增加来源链接和一句主旨，已有主题按需更新。
