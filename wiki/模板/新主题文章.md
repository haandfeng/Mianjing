# 新主题文章模板

输出位置：`wiki/技术主题/<主题名>.md`。这里维护该主题的一份完整当前解释。

## 写之前

1. 先读 [[index]] 与 [[索引/主题]]，搜索 `wiki/技术主题/`、`wiki/Agent问题答案/` 和相关资料；已有主题就更新或补章节。
2. 确认问题需要独立讲解后再新建。参考原文、外部摘录保留在 `资料/学习材料/`，不要求先写长篇材料再另写一篇压缩版。
3. 术语按仓库证据判断熟悉程度：已掌握的直接用，见过不牢的补一句定义，未学过的先定义再使用；英文缩写展开并给中译，不使用生活比喻。
4. Agent / LLM 产品机制、框架实现和 API 行为先查最新源码及近期资料，结论标明来源类型与置信度；旧笔记只作线索。

正文按下面四层组织。定义只使用已掌握的词，机制需要图示时使用 Mermaid；向用户逐段讲解时，结尾校准“哪个术语是你之前没学过的”。
