# 新面经原文模板

手敲面经或创建待填写档案时，复制下面正文到 `资料/面经/<公司>/<BU>/<标题>.md`；BU 未知可直接放公司目录。不另建复盘目录，也不调用复盘脚本。

## 填写规则

- 只记录有证据的问题和当时回答；还没补充的地方留空，不让 LLM 推测。
- 逐题复盘一次只讨论一题：先列当时回答，等本人判断，再共同打磨；确认后写“当时复盘 / 改进摘要”。
- 原有历史复盘保留原貌。完整通用答案维护在技术主题，完整项目答案维护在项目追问，面经只保留摘要和链接。
- 转载只保留来源已有回答；没有回答就列问题，不自动编一份答题骨架当作原文。
- TikTok / TT 归入字节；算法内容在另一个仓库。

## 收尾

- [ ] 核对属性、来源与问题顺序，不填未经确认的现场回答。
- [ ] 对应公司画像增加来源链接与一句主旨。
- [ ] 讨论确认的通用知识更新主专题，项目答案更新项目追问。
- [ ] 同步受影响的索引，追加操作日志。
- [ ] 运行 `python3 wiki/scripts/lint_wiki.py`，确认 wiki 无断链。
