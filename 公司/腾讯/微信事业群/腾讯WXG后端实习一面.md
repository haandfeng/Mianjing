## 2. 计算机基础

### Q：进程、线程、协程的区别
- 进程：资源分配基本单位，独立地址空间，切换开销大（换页表 / TLB 失效）
- 线程：CPU 调度基本单位，共享所属进程地址空间，切换换寄存器 + 栈 + 进内核
- 协程：用户态轻量「线程」，程序自己协作式调度，切换只存恢复少量上下文、不陷内核，一个线程可跑成千上万协程

### Q：协程什么时候调度？操作系统层面切换的条件？
- 协程是协作式：遇到主动让出点（`await` IO、`yield`、channel 阻塞）才切，不被抢占
- OS 线程切换触发：时间片用完、更高优先级就绪、系统调用阻塞、中断
- 协程切换不触发 OS 上下文切换（不进内核），所以比线程切换快

### Q：浏览器输入 URL 到页面展示的全过程
- DNS 解析拿 IP → TCP 三次握手 → （https）TLS 握手 → 发 HTTP 请求
- 服务器处理返回 → 浏览器解析 HTML 建 DOM、解析 CSS 建 CSSOM → 渲染树 → 布局 → 绘制；期间下载/执行 JS

### Q：HTTPS / TLS 握手过程
- Client Hello（密码套件 + 随机数）→ Server Hello（选套件 + 随机数 + 证书）
- 客户端验证证书（CA 签名链）→ 密钥交换（ECDHE 生成 pre-master）→ 双方各自算出会话密钥 → 切对称加密通信
- TLS 1.3 精简到 1-RTT（详见 [[TCP与HTTPS]]）

### Q：TCP 四次挥手流程和各状态
- 主动方发 FIN → `FIN_WAIT_1`；被动方回 ACK → 主动方 `FIN_WAIT_2`、被动方 `CLOSE_WAIT`
- 被动方发 FIN → `LAST_ACK`；主动方回 ACK → `TIME_WAIT`（等 2MSL）→ `CLOSED`
- TIME_WAIT 等 2MSL：保证最后 ACK 送达 + 旧报文消散

### Q：MySQL 索引底层数据结构、B+ 树特点
- B+ 树：多路平衡，数据全在叶子，叶子间双向链表（利于范围查询）
- 非叶子只存索引键，树矮（3~4 层扛千万级），磁盘 IO 次数少

### Q：聚簇索引与非聚簇索引的区别、回表
- 聚簇（InnoDB 主键）：叶子存整行；非聚簇（二级索引）：叶子存主键值
- 回表：二级索引查到主键 → 再回聚簇索引取整行；覆盖索引可免回表（见 [[MySQL索引与执行计划]]）

### Q：索引使用方法 + 什么情况失效
- 失效：最左前缀断裂、索引列上加函数/运算、隐式类型转换、`like '%x'` 前导通配、OR 连非索引列、范围条件右边的列

### Q：事务 ACID 特性及实现（undo log / redo log / MVCC）
- 原子性 → undo log 回滚；持久性 → redo log 崩溃恢复；隔离性 → MVCC + 锁；一致性 → 前三者共同保证
- MVCC：ReadView + undo 版本链，RR 下同一事务一次快照读（见 [[MySQL-MVCC与隔离级别]] / [[InnoDB事务与锁]]）

### Q：进程间通信方式
- 管道 / 命名管道、消息队列、共享内存（最快）、信号量、信号、socket（跨机）
