## 牛客版

**标题：** 快手人才计划 数据平台 Data Agent 一面

**正文（直接粘贴）：**

```
人才计划。
没有八股，也没问数据库和 Java，全程围绕项目拷打，外加两道算法。
结果：过，进二面。

【一、多 Agent 问答系统项目相关提问】
1. 简历里你自己最熟悉的是哪个项目。
2. 这个项目里对你来说最有挑战的是哪件事。
3. 项目整体架构介绍一下，你二次开发的主要内容是什么。
4. 为什么要做多 agent，单 agent 满足不了现在的业务场景吗。
5. ReAct 循环越多、上下文加载越多，碰到上下文膨胀或超限怎么处理。
6. 通用做法是 summary，但每个模型压缩完结果不一样、也可能丢失原意，
   怎么让压缩过程更符合原意。
7. 准确率是怎么测评的，测评过程中怎么保证不重不漏。
8. 你验证的都是核心、常见问题，不常见的就不验了吗。
9. 你们的记忆系统是怎么做的。
10. 你主要用什么语言，我看之前项目也有用 Java。

【二、Agent 工程化类提问】
1. 项目里也用 skill 吧，用在哪一层。
2. 大模型不一定按你编写的流程走，怎么提高 skill 里流程的执行命中率。
3. 假设流程是「取数据 → 用 pandas 分析 → 给结论」，实际会出三种问题：
   模型跳过分析那一步、给假分析（拿上一次结果直接返回）、每次分析结果
   都不稳定。有什么工程化的办法解决。
4. workflow 有什么问题吗。
5. 还有别的思路吗，有没有一些工程化的思路呢。
6. 这是 harness 架构，在 harness 工程里怎么降低大模型幻觉。
7. Claude Code 的记忆系统了解吗。
8. 它这个记忆里分短期记忆和长期记忆吗。

【三、算法（两道）】
1. 给一个含正负数的数组，找出相加和最大的连续子数组，返回它的和。（LC53）
2. 时间空间复杂度是多少，还有优化空间吗。
3. 给一个不重复的数字集合，返回所有子集（含空集）。（LC78）
4. 你每次 DFS 遍历的时候，是从哪个位置开始的。

秋招信息差太大了，想找组织一起交流。同投 Agent／大模型岗的友友对对流程

#秋招# #面经# #校招# #快手# #agent# #大模型# #数据# #互联网大厂#
```
