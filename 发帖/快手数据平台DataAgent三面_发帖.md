## 牛客版

**标题：** 快手人才计划 数据平台 Data Agent 三面

**正文（直接粘贴）：**

```
人才计划。
没有八股、没有算法、没有现场设计题，全程围绕项目机制和指标口径追问。
结果：未知。

【一、多 Agent 问答系统项目相关提问】
1. 展开讲一讲这个项目。
2. 之前没有这类产品吗，为什么还要做。
3. 通用 AI 问答产品为什么解决不了这个问题。
4. 读代码为什么不用 coding agent。
5. 系统如何保证回答尽可能覆盖所有业务分支。
6. 决策树、门禁和审核分别怎么实现。
7. 这套 flow 后续有新诉求，谁来调、怎么调。

【二、Prompt Cache 与会话管理】
1. prompt cache 具体在哪一层做优化。
2. 缓存命中率怎么算，分母是什么。
3. 结合真实用户问答，整体命中率大概能到什么量级。
4. 为什么一轮对话就能结束，怎么保证用户会起新 session。
5. 用户追问时上下文怎么续。
6. 群会话多人同时提问时怎么做 session 隔离，是否会监测群消息。

【三、评测与数据飞轮】
1. 项目效果怎么评测。
2. 打分怎么换算成准确率，指标的定义和分母分别是什么。
3. 专家评审从哪来，为什么愿意长期参与。
4. 数据飞轮后续能不能持续运转。
5. 最终效果怎么度量，怎么让闭环真正跑起来。
6. 知识库大概有多少文档，规模怎么估算。

秋招信息差太大了，想找组织一起交流。同投 Agent／大模型岗的友友对对流程

#秋招# #面经# #校招# #快手# #agent# #大模型# #数据# #人才计划#
```
