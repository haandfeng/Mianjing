## 牛客版

**标题：** 懂车帝创作平台 AIGC 方向秋招一面

**正文（直接粘贴）：**

```
没有八股，也没问数据库和 Java：一整块跟项目无关的 Agent 通用概念题，
加上项目拷打和 AI coding 三连，最后一道算法。面试官一题一问，问完
就走下一题，几乎不连着追。
结果：挂。

【一、多 Agent 问答系统项目相关提问】
1. 介绍一下你最熟悉的 agent 项目，目标是什么、你负责哪部分、具体怎么做的。
2. 多 agent 编排这块是怎么做的。
3. agent 与 agent 之间的通信是怎么做的。
4. 做多 agent 编排的时候遇到过哪些难点，怎么解决的。
5. 你的退出逻辑是怎么做的。
6. 你的评测飞轮是怎么做的。

【二、Agent 通用概念题】
1. agentic 里面 skill、workflow、tool、agent 各自的职责和边界是什么。
2. 什么时候会用 skill，什么时候用 workflow。
3. 实际场景里，workflow 在哪些场景下是必须的。
4. 什么是 agent 的上下文工程。
5. 企业级的 agent 应该具备哪些能力。

【三、知识库相关】
1. 做这个项目的时候，有没有想过构建一个知识库。
2. 知识库的上下文命中怎么做，怎么保证它是能命中的。

【四、AI coding 三连】
1. 怎么做一个安全且闭环的 vibe coding，人工 review 会看哪些内容。
2. 拿到需求的时候，除了测试用例，你还会做哪些工作。
3. vibe coding 里面有个 AGENTS.md，你会在里面写什么规则。

【五、编码题】
题面：给一排柱子的高度，选两根柱子和 x 轴围成一个容器，求最大储水量。
   示例数组 [1,8,6,2,5,4,8,3,7]，答案 49。（LC11 盛最多水的容器）
1. 写完之后讲一下你的整体思路。

秋招信息差太大了，想找组织一起交流。同投 Agent／大模型岗的友友对对流程

#秋招# #面经# #校招# #懂车帝# #agent# #大模型# #AIGC# #互联网大厂#
```
