## 牛客版

**标题：** 点点互动人才计划 AI Agent 一面

**正文（直接粘贴）：**

```
人才计划，共 4-5 轮。
没有八股，先算法后项目，剩下全程围绕项目拷打，最后加两道概念题。
结果：过，进业务二面。

【一、算法（禁 AI，投屏手写）】
1. 从 word1 取一个字符与 word2 的一个字符互换，判断能否使两个字符串中
   不同字符的数目相等。（LC2531，Medium）
2. 你这个实现的时间复杂度是多少。
3. 还有没有优化空间。

【二、多 Agent 问答系统项目相关提问】
1. 从用户输入到最终结果返回，完整链路是什么样。
2. 为什么多 Agent 编排能提高准确度。
3. 引入 review agent 带来了什么新问题、有什么缺点。
4. review agent 和主 agent 用相同模型／不同模型，各有什么优势。
5. 决策树和直接让大模型自由选择，区别在哪。
6. 网关适配三家协议，为什么不能只替换请求地址。
7. 流式输出和普通响应都适配了吗，额外多做了哪些处理。
8. token 在不同协议中有哪些差异。
9. prompt cache 为什么能生效，一般缓存哪些内容。
10. 什么是事件循环，为什么跨事件循环复用连接会出错，本质是什么。
11. 一次 agent trace 还应该包含哪些核心内容。
12. 如何判断准确率提升是真的提升，而不是测试集的偶然波动。
13. 日常写代码用 code agent 吗，有没有模型总也改不对的情况。

【三、性能量化工具项目相关提问】
1. onCPU 和 offCPU 分别表示什么。
2. 你做的性能量化工具，具体是怎么量化优化收益的。
3. 同一段 CRC 代码在 ARM 和 x86 上为什么性能不同。

【四、Agent 概念类提问】
1. ReAct 范式的基本执行过程是什么。
2. ReAct 有哪些常见问题。

秋招信息差太大了，想找组织一起交流。同投 Agent／大模型岗的友友对对流程

#秋招# #面经# #校招# #agent# #大模型# #提前批# #互联网大厂#
```
