## 牛客版

**标题：** 米哈游提前批 Agent 方向一面

**正文（直接粘贴）：**

```
提前批。
没有八股，也没问数据库和 Java：前半段是大模型原理和概念题，后半段围绕项目
拷打，中间夹一道很轻的手写题（两道里二选一）。
结果：挂。

【一、AI coding（连着追了三问）】
1. 你怎么用 AI coding 的。
2. 怎么保证 AI coding 生成代码的质量。
3. 有没有工程化的方式，保证编码的有效性。

【二、手写题（二选一）】
题面 A：Python 实现一个装饰器，打印 log。
题面 B：ACM 模式。输入若干组（售价、售出、买入），输出售价最便宜的前 4 个，
并且售出和买入都不为 0。

【三、大模型概念题】
1. AI 的幻觉原理是什么。
2. DeepSeek、OpenAI 这些 API 有什么接口。
3. 怎么解决 AI 回答的事实度、忠实度。
4. Skill 和 MCP 的区别。
5. Skill 有什么特性。
6. 你认为游戏 agent 有什么发展方向。

【四、多 Agent 问答系统项目相关提问】
1. 你这个项目的 agent 整个流程是怎么样的，以一个 query 为例讲一下。
2. 多轮对话怎么压缩，怎么处理 context window。
3. 做 summary 的时候有什么要点，怎么保持关键信息。
4. 用户如果同时发送两个对话，你是怎么解决的、怎么处理的。
5. 你是怎么实现 AI 的 steer 的，就是续接说话。
6. 你是怎么做 trace 的，agent 开发有什么需要记录的重点信息。

秋招信息差太大了，想找组织一起交流。同投 Agent／大模型岗的友友对对流程

#秋招# #面经# #校招# #米哈游# #agent# #大模型# #提前批#
```
