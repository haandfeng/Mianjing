## 牛客版

**标题：** 阿里国际阿里星 Agent Infra 一面

**正文（直接粘贴）：**

```
阿里星（Bravo Star）顶尖人才计划。
没有八股，也没问数据库和 Java：前半段围绕项目拷打，重点在「单实例的
东西怎么变成多租户平台」这条线上连追了七问，后半段问 memory 的业界
调研，最后一道算法。
结果：过。

【一、多 Agent 问答系统项目相关提问】
1. 这个项目解决的是什么问题，你整体是怎么设计的。
2. 门禁在技术上具体是怎么实现的。
3. 决策树的高度和宽度怎么保障。
4. 知识库怎么建设的，研发要看到代码粒度、产品运营要的是文档粒度，
   每个角色的知识上下文不一样，这条链路你怎么维护。
5. 上下文怎么控制。
6. 打通模型网关接了多种模型，从产品态到技术态是什么链路。
7. prompt cache 是在什么环节实现的。
8. 支持多模态吗。
9. 这个智能体怎么做评测。

【二、运行时与水平扩展连环追问】
1. 运行时是什么架构，是微服务还是沙箱。
2. 支持集群部署吗。
3. SLA 怎么保障，重启的时候服务不掉。
4. 多用户的 session 怎么隔离。
5. 历史会话怎么持久化，存储结构是什么。
6. 工作区是按用户隔离还是按 session 隔离。
7. 对话过程中会生成一些临时文件产物、或者交付的 artifact，
   多实例之间怎么做到共享。

【三、Agent 记忆系统项目相关提问】
1. 讲一下你这个项目具体在做什么。
2. 自进化的 memory 是怎么设计的。
3. 这套 memory 怎么对外透出、怎么接进框架里。

【四、Agent 通用概念题】
1. RAG 和 LLM wiki 的区别是什么。
2. LLM wiki 的原理是什么。
3. 什么场景适合用 RAG，什么场景适合用 LLM wiki。
4. skill 的加载和运行机制是怎么样的。
5. prompt cache 的原理是什么。
6. 调研过业界的 memory 方案吗，跟 Mem0、Claude Code、
   Codex 有什么区别。
7. verify 需要针对特定场景，coding agent 有验证样本摆在那；
   如果是一个通用办公型的 agent，它的 memory 应该怎么设计。

【五、AI coding 与工程习惯】
1. 你个人的 AI native workflow 是什么样的。
2. 平时通过什么渠道关注这个领域的最新进展。
3. 自己有没有做过什么小工具。

【六、算法题】
题面：给定一个字符串，找出其中不含有重复字符的最长子串的长度。
```
