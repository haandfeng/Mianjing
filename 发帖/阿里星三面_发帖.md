## 牛客版

**标题：** 阿里星 Agent Infra 三面

**正文（直接粘贴）：**

```
阿里星 / Bravo Star 顶尖人才计划。
没有八股，技术负责人和 HR 一起面。技术部分围绕 memory、知识工程和多 Agent 深挖。
结果：未知。

【一、Agent 记忆系统与运行时】
1. 这个系统解决什么问题，核心挑战是什么。
2. 远程设备遇到异常状态时怎么处理。
3. 自进化 memory 用在哪，解决什么问题，怎么整合到系统里。
4. memory 怎么衡量效果，是否有分类，你在其中的核心贡献是什么。
5. 为什么隔离必须放在一台机器上，两台机器为什么不行。
6. 隔离方案里最有成就感的点是什么，具体挑战和代码量级怎样。
7. AI coding 过程中遇到什么具体挑战，学到了什么。
8. Memory 和知识工程分别是什么，两者是什么关系。
9. 什么场景需要 memory，为什么多 Agent 问答系统反而关掉了 memory。
10. 行业内有哪些类似的 memory 工作，哪些值得借鉴，哪些不同。

【二、多 Agent 问答系统项目相关提问】
1. 简单问答为什么从单 Agent 拆成多 Agent。
2. LLM Wiki 做了吗，代码更新后为什么不更新 Wiki。
3. 做过大模型推理链路的性能、成本或体验优化吗。

秋招信息差太大了，想找组织一起交流。同投 Agent／大模型岗的友友对对流程
```
