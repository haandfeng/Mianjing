## 2. 计算机基础

### Q：用过 C++ 吗？
- WXG 技术栈偏 C++，被问到语言背景很常见；没用过就如实说 + 强调底层原理相通

### Q：进程、线程、协程的差异？协程什么时候调度？
- 同一面又问了一遍（连问两轮 → WXG 必背）；协程协作式调度，遇 IO/yield 让出，见一面骨架

### Q：什么时机会发生阻塞？
- 等待 IO（磁盘/网络）、等待锁、主动 sleep、等待条件变量/信号量

### Q：MySQL 索引的理解（从 B+ 树讲起）
- B+ 树结构 → 聚簇/二级 → 回表/覆盖 → 失效场景，见 [[MySQL索引与执行计划]]

### Q：Redis 用过哪些数据结构？底层实现是什么？
- String(SDS)、List(quicklist)、Hash(listpack/dict)、Set(intset/dict)、ZSet(listpack/skiplist)，见 [[Redis数据结构与大Key]]

### Q：用 Redis 怎么实现排行榜？
- ZSet：`ZADD` 记分、`ZREVRANGE`/`ZREVRANK` 取榜和名次；大规模可分段/定期归档

### Q：进程在内存中的空间布局？
- 从低到高：代码段(text) → 数据段(data/bss) → 堆（向上长）→ 共享库映射区 → 栈（向下长）→ 内核空间

### Q：IO 多路复用？select/poll/epoll 区别？epoll 的 LT 和 ET？
- select：fd 上限 1024、每次全量拷贝+线性扫；poll：链表无上限但仍线性扫
- epoll：红黑树管 fd + 就绪链表回调，O(1) 拿就绪事件
- LT：只要可读就一直通知（默认，好写）；ET：状态变化只通知一次，必须一次读干净（配非阻塞 IO）
- 见 [[Linux与IO模型]]

### Q：分布式存储了解吗？Redis 集群？
- Cluster：16384 slot 分片、gossip、主从 + 故障转移

### Q：分布式协议？Raft 核心思想？CAP？
- Raft：Leader 选举（任期+多数派投票）、日志复制（多数派提交）、安全性（日志更新者才能当选）
- CAP：分区容忍必选，实际在 C 和 A 之间取舍

### Q：进程间通信方式？本机进程间通信用哪种 socket？
- 管道/消息队列/共享内存/信号量/信号/socket；本机用 **Unix Domain Socket**（不走网络协议栈，比 TCP loopback 快）

## 3. 算法题（只记题面，解法去算法仓库）

- **LFU Cache**（同时支持 LRU + LFU 淘汰）
- **消消乐**：相邻两数之和为 10 则抵消（栈）

## 4. 开放题

### Q：RAG 要召回多个子系统（会议/文档/日常）的数据，各子系统耗时不一，怎么优化整体召回耗时？
- 并行扇出 + 总超时预算；快的先返回，慢的设子超时、超时降级（跳过或用缓存兜底）
- 分级召回：先便宜的（缓存/倒排）再贵的（向量），够用即止
- 对慢子系统做预取/物化，异步刷新
